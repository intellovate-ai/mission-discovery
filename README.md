# Mission: Discovery

A multiplayer space mission design game. Entry for the 2026 NASA Space Apps Challenge
("Space Mission Design Game"), team **Intellovate Red Planet Recon**, Space Apps Seattle.

## Status

The hackathon runs Sat 2026-11-14 9:00 AM to Sun 2026-11-15 11:59 PM (Seattle time).
Everything before that is a blank, game-agnostic starter: a Next.js app with three.js,
React Three Fiber, drei, postprocessing and zustand installed, plus one spinning cube to prove
3D renders. All game code is written during the hackathon.

## Run

```bash
pnpm install
pnpm dev
```
